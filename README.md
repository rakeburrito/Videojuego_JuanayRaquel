# Videojuego Plataformer
# Juana Agudelo Acevedo y Raquel Restrepo Herrera
 1. Cofre: Objeto interactuable para conseguir monedas adicionales y le da más puntaje.
 2. Enemigo: El enemigo podrá matar al jugador si se acerca mucho a él. 
 3. Sonido: Por cada interacción o acción (Abrir el cofre, saltar, morir, victoria, derrota, música de fondo, etc.)
